API reference / Beta / Tunnels

List Tunnels Beta

Returns a paginated list of tunnels available to the authenticated workspace.

List tunnels

Retrieve tunnel records with the Anthropic SDK. This endpoint is currently available through the beta API.

GET/v1/tunnels
Query parameters
before_idstring

Return objects before this object ID. Use this cursor to page backward through the collection.

after_idstring

Return objects after this object ID. Use the value from the previous page to continue forward.

limitinteger

The maximum number of tunnel objects to return in one page.

Returns
data array of tunnel objects

The tunnels available to the current workspace.

has_more boolean

Whether another page of results is available.

first_id / last_id string or null

Cursor IDs for navigating between pages.

Response
