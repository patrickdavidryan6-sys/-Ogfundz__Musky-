Tool pattern 04

A tool for fetching one invoice.

A focused, read-only server tool with a typed input, explicit behavioral annotations, and structured output that clients can render with confidence.

METHOD fetch_invoiceINPUT invoiceId: stringACCESS read only
fetch-invoice.ts
export const fetchInvoice = server.tool(  {    name: "fetch_invoice",    description: "Fetch one invoice by invoice ID.",    inputSchema: z.object({ invoiceId: z.string() }),    annotations: {      readOnlyHint: true,      destructiveHint: false,      openWorldHint: true,    },  },  async ({ invoiceId }) => {    const invoice = await billing.findInvoice(invoiceId);    if (!invoice) {      return {        isError: true,        content: [{ type: "text",          text: `Invoice ${invoiceId} was not found.` }],      };    }    return {      content: [{ type: "text", text: JSON.stringify(invoice) }],      structuredContent: invoice,    };  },);

Behavior, made explicit.

Annotations help clients use tools safely.

01 / READ ONLY

Safe to inspect

The tool retrieves data without changing invoices, accounts, or billing state.

02 / NON-DESTRUCTIVE

Nothing is deleted

Calling this tool cannot remove or overwrite the customer's existing data.

03 / OPEN WORLD

External data access

The tool reaches beyond the client to query the connected billing system.
