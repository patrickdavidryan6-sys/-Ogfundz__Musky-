API reference / Chat Completions

Chat Completions

Given a list of messages comprising a conversation, the model will return a response.

Create chat completion

Creates a model response for the given chat conversation. Learn more in the text generation guide.

POST/chat/completions
Request body
messagesarrayRequired

A list of messages comprising the conversation so far. Depending on the model, different message types are supported.

modelstringRequired

ID of the model to use. See the model endpoint compatibility table for details on which models work with Chat Completions.

audio object or null

Parameters for audio output. Required when audio output is requested with modalities: ["audio"].

frequency_penalty number or null

Number between -2.0 and 2.0. Positive values penalize new tokens based on their existing frequency.

max_completion_tokens integer or null

An upper bound for the number of tokens that can be generated for a completion.

modalities array or null

Output types you would like the model to generate. Most models generate text by default.

tools array

A list of tools the model may call. Currently, custom tools and functions are supported.

tool_choice string or object

Controls which tool is called by the model: none, auto, required, or a named tool.
