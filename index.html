API reference/Vector stores/Files

Vector store files

Update file attributes

Attach or replace custom attributes on a file in a vector store. Substitute your vector_store_id and file_id before sending the request.

POST cURL 
curl https://api.openai.com/v1/vector_stores/{vector_store_id}/files/{file_id} \
  -H "Authorization: Bearer $OPENAI_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"attributes": {"key1": "value1", "key2": 2}}'
Keep your API key secret and load it from the OPENAI_API_KEY environment variable rather than placing it directly in source code.
